# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.x (latest minor) | ✅ |

## Reporting a vulnerability

These packages parse untrusted request input — security reports are taken seriously.

Please do NOT open a public issue for security problems. Use GitHub's private vulnerability reporting ("Report a vulnerability" under the repository's Security tab). You will get an acknowledgement within a few days; a fix or mitigation plan follows for confirmed reports before any public disclosure.
